NAND2Tetris Compiler & Operating System

I wanted to learn more about computing fundamentals, so I enrolled and completed the NAND2Tetris courses created and taught by professors Shimon Schocken and Noam Nisan: https://www.nand2tetris.org/

It's a little difficult to demo this work, so I have a video recording of my final project: a program I wrote, in a language compiled by a compiler I wrote, running on an operating system I wrote. Pretty neat!

Source code:

  • JACK Compiler (written in Python and Assembly): https://github.com/FunHaver/JackCompiler
  • Operating System (written in Jack): https://github.com/FunHaver/JackOS
  • Spike Runner (a game written in Jack to run on the operating system): https://github.com/FunHaver/JackOS
